# Solicitud OIRS — datos de evacuación y puntos de encuentro del Villarrica

**Destino sugerido:** Municipalidad de Pucón, Dirección de Gestión del Riesgo de Desastres; con copia a SENAPRED Araucanía.

## Texto para enviar

Solicito orientación y, si corresponde, copia o enlace oficial a:

1. el Plan Comunal de Emergencia vigente de Pucón;
2. las áreas de evacuación, vías de evacuación y puntos de encuentro para amenaza volcánica del Villarrica;
3. la versión y fecha de actualización de cada capa o plano;
4. el canal autorizado para reutilizar esos datos en una aplicación comunitaria informativa que siempre atribuirá la fuente y enlazará al documento original.

La aplicación no pretende reemplazar a SERNAGEOMIN, SENAPRED, el SAE ni las instrucciones de la autoridad. Los puntos actualmente visibles están rotulados como **por confirmar** y no se presentarán como oficiales hasta recibir una fuente verificable.

## Evidencia que guardar

- número de solicitud y fecha;
- respuesta completa y archivos originales;
- URL o documento de origen;
- versión/fecha de la capa importada;
- autorización o condición de reutilización;
- responsable que aprobó la importación.

Cuando exista una respuesta verificable, usar `scripts/import-safety-zones.ts` con
`--source-url`, `--documento`, `--fecha` y `--trazabilidad oficial`. No hacer
scraping del visor ni importar puntos sin esa trazabilidad.
